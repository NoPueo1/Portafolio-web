03 / Backend & Arquitectura Distribuida

Sistema de Cotización y Gestión en Microservicios

Ecosistema distribuido de 11 módulos con Spring Boot 3.2.5, OpenFeign y 10 bases de datos MySQL

Código

Plataforma desacoplada para cotizaciones, inventario y facturación. Implementa un Gateway central (ms-gateway:8090), comunicación síncrona declarativa con OpenFeign entre servicios, 10 esquemas MySQL aislados bajo el patrón Database-per-Service y pruebas unitarias con JUnit 5 & Mockito.

STATUS: 200 OK 
@FeignClient(name = "ms-stock")
public interface StockClient {
    @GetMapping("/api/stock/equipo/{equipoId}")
    StockDTO obtenerStockPorEquipo(@PathVariable("equipoId") Long equipoId);

    @PutMapping("/api/stock/descontar")
    void descontarInventario(@RequestBody DescuentoStockDTO dto);
}
@Bean
public RouteLocator customRouteLocator(RouteLocatorBuilder builder) {
    return builder.routes()
        .route("ms-cotizador", r -> r.path("/api/cotizaciones/**")
            .uri("http://localhost:8081"))
        .route("ms-stock", r -> r.path("/api/stock/**")
            .uri("http://localhost:8085"))
        .build();
}
-- Patrón Database-per-Service: 10 Esquemas Aislados MySQL

Arquitectura del Ecosistema de Microservicios

sistema-cotizacion-microservicios (11 Módulos)

ms-gateway (Puerto 8090)

Reverse Proxy y enrutamiento centralizado bajo Spring Cloud Gateway. Administra el tráfico sin exponer puertos individuales.

ms-cotizador / ms-itemcotizador

Módulo nuclear de cotizaciones. Consume síncronamente los servicios de stock y clientes a través de clientes declarativos OpenFeign.

ms-stock / ms-equipo / ms-categoria

Control de inventario, stock disponible y catálogo técnico de equipos con esquemas de base de datos aislados.

ms-facturacion / ms-notificacion / ms-proveedor

Emisión de documentos tributarios, gestión de proveedores y despacho de alertas asíncronas.

10 Esquemas MySQL (Database-per-Service)
